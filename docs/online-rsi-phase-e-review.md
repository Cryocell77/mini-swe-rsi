## 实现与审查

1. `ContextBudget` 必须接收明确的服务能力，删除隐式 32768/2048 模式、旧合同及 provider 真/假分支。合法 provider 路径保持原有行为；服务真实 usage 仍决定容量与计量。Qwen tokenizer 的库版本、文件摘要和服务身份验证保留，已核验内容审计继续只计算 provider-bound content，不把 reasoning 回放当作已知服务封装。
2. 删除 `common_tasks` 的空合同、计划字段、公开输出项和共同任务验收循环。当前题不退化、已声明修复或机制标准、源码与执行摘要、独立启动及私有评分证据继续执行。显式共同任务字段在适用入口被拒绝，不能忽略其要求后接任。
3. 在线合同升级为 `mini-swe-rsi-online-v3`，`check_policy.revision=2`；SICA improvement 协议保持 v6，实际七步模型协议未改。旧 v2 运行和冲突协议不能重标为 v3；旧产物通过对应 Git 版本处理。上下文实现文件加入控制摘要，防止单独替换其逻辑后恢复。
4. 删除 CLI 的无效 `--resume`，同一 `--run` 的持久化恢复保持；删除 bridge 的无效 `--timeout/--cost-threshold`。保留 `--resume-checkpoint/--resume-workflow` 和宿主实际执行的期限、费用守卫。禁用参数缩写，旧 `--resume` 不会误指向恢复授权参数。
5. 主 agent 合并重复的启动合同校验与计划拒绝分支，修正旧版本报告测试提前触发协议错误的问题；测试现在分别验证实际错误分支。历史上下文测试迁到显式服务能力及适用的已核验 tokenizer，未删除输入完整性、错误消耗或未知费用覆盖。

本批是兼容路径收敛，新增兼容边界与拒绝检查抵消了删除量：自有生产 Python 从 6,008 行变为 6,019 行，净增 11 行（含空行与注释，`src/`、`runtime/`）。不以减少行数替代行为与身份验收。
