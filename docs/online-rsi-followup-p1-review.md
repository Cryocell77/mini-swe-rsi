2. 工作流删除 `execute()` 内未消费的 `op` 与 `call_role()` 内未使用的 `definition`；委员会调用处明确丢弃未消费的返回身份。真正参与缓存、恢复和角色事件的 `role_identity` 保留；别名解析仍由 `dispatch()` 执行。没有修改角色提示、工具权限、提交格式、委员会或阶段状态机。
3. 预算删除 `fileview_regeneration_chars` 与 `fileview_regeneration_implemented`。其他资源键、值及校验保持，尤其保留 300,000 字节内联、8 MiB 上限与完整输出产物保护，不能把这些误认为同一个未实现功能。

主 agent 将评分器新增的两个拒绝分支收敛为统一的非 `score` 拒绝，避免留下不必要的旧操作特判；删除只断言函数名称消失的测试，补充实际有效评分入口回归。没有扩大到其余兼容格式或 mini 包裁剪。
