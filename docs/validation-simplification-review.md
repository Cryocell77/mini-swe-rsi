# 格式校验与错误处理精简审查

日期：2026-10-19。基点：`8f267ba`。用户要求检查全项目的格式校验和错误处理，并简化非必需部分。

## 审查原则与范围

检查了全部 22 个自有生产 Python 模块、bootstrap，以及固定 mini 的实际 agent／文本动作／环境异常入口。静态清单中 917 行匹配校验或错误处理相关语法；这不是独立校验数量，也不是运行覆盖率。固定上游、计费删除补丁和包裁剪清单不修改。

模型请求、服务响应、持久文件及独立进程输入继续验证。宿主已构造、或在同一路径已验证的对象直接使用；不同进程与接任边界仍各自验证，不因“之前检查过”而跳过。

## 全模块处置

| 模块或范围 | 删除／合并的非必要实现 | 保留的行为及理由 |
|---|---|---|
| `broker.py` 候选注册 | 删除 callable 防御、可选 metadata 默认值、伪造 registered 记录再做完整验证 | 内部函数要求显式 metadata；读取已有记录时仍完整验证，重复注册身份必须一致 |
| `broker.py` 候选记录 | 将重复类型／缺字段检查合并；按完成、失败／中断、活动三类验证字段 | 原五种合法状态和身份约束不变；非 completed 不得带结果，失败错误可含空消息 |
| `broker.py` 模型请求 | 用一次字典精确比较替代缺字段、多字段、集合及值的多次比较 | 缺字段、多字段、私有字段和错误身份仍拒绝；会话、角色、任务注册绑定保留 |
| `broker.py` 服务故障 | 合并重复错误脱敏分支，删除暂停政策的重复判定 | 不泄露 provider 原始错误，原故障类别、用量记账及 sticky pause 保留 |
| `broker.py/context_budget.py/budget_policy.py` | 模型身份初始化只通过 ContextBudget 校验一次容量 | provider 能力声明、整数／布尔区分、上下文与输出关系、迭代和请求限额保持 |
| `online.py` | 删除内部 identity 的完整格式复验、已验证结果的类型复验；删除稍后精确摘要比较已能拒绝的重复空值检查 | 任务／父／候选来源、同 attempt 取证、公开／私有评分一致、冻结与不可变接任／恢复不变 |
| `driver.py` | 删除宿主对已移除 CLI 参数的额外黑名单；合并普通容器与 relay 的清理循环 | bridge 参数解析器仍拒绝未知参数；活动版本绑定、独立执行、评分恢复及 best-effort 清理保留 |
| `runtime/bridge.py` | 恢复身份改为一次完整字典比较 | 多字段、缺字段和值不匹配仍拒绝；私有授权、状态与源码摘要核验保留 |
| `runtime/workflow.py` | 删除较宽状态集合后再检查较窄集合、重复协调者权限检查、重复证据引用验证及已知非空缓存项判断 | 活动阶段限定、角色权限、诊断证据、冻结计划、委员会来源、恢复计数继续验证 |
| `report.py/cli.py` | 删除共享协议校验已覆盖的对象检查；删除 report 分支返回后必然为 online 的条件 | 公共过滤、部分故障报告、原始错误保留和报告错误传播保持 |
| `core.py/archive_view.py/source_hash.py/online.py` | 删除 is_file/is_dir 已包含的 exists 判断 | 链接拒绝、目录边界、摘要、公开名单及文件缺失语义保持 |
| `online.py` 异常分支 | 删除 ValueError 元组中重复的 JSONDecodeError 子类 | 文件错误仍转为对应领域错误；未统一吞掉或混淆拒绝、中断和基础设施故障 |
| `recovery.py` | 不删除宿主授权及累计消耗验证 | 宿主和容器面对独立输入，各自核验具有实际边界意义 |
| `stage_tools.py/tool_output.py` | 不删除阶段权限、挂载校验、超时与输出保护 | 防止越阶段写源码、失控输出及遗留进程；finally 清理不是可删的错误掩盖 |
| `grader.py` | 保留评分操作、冻结镜像、TLS／配方缓存和官方失败分类 | 防止混用镜像与评分资产；已知任务失败不能变成基础设施重试 |
| Data、镜像库存、`harness_seed.py`、bootstrap | 保留数据／来源／补丁／裁剪身份及原子发布检查 | 不同输入和发布阶段需要独立验证，不属于同一个可信对象的重复类型检查 |
| `public_filter.py/runtime/relay.py` | 保留隐私过滤、请求入口及传输失败处理 | 过滤和边界错误转换是功能，不以内部代码已验证为由删除 |
| 固定 mini 入口及 `__init__.py` | 不修改固定上游；空初始化模块无需处理 | FormatError、Submitted、超时及轨迹保存参与正常 agent 生命周期；不能整体移除 |

保留当前协议、源码记录和机制计划的旧字段拒绝规则。这些少量检查定义既有输入契约；本轮优先删重复实现，不扩大模型或持久记录的合法输入集合，也不引入新的通用校验框架。

## 验证与规模

- 对照基点纯函数，候选持久记录 **29,155 组**身份／状态／结果／错误组合的接受与拒绝结果一致；服务错误脱敏 **61 组**响应结果一致。比较脚本仅在本机执行，不作为依赖 Git 历史或临时文件的仓库测试。
- 首轮定向回归 189 项通过、1 项因统一错误提示未包含 `evidence_refs` 字段名失败；保留原拒绝行为，补回明确字段名后，定向回归 **191 项通过**。
- 模型身份、服务故障、输入完整性、上下文与资源政策回归 **91 项通过**，仅有既有 LiteLLM event loop 弃用警告。
- 新增实际 Broker 行为回归：缺字段、额外字段、私有字段和错误父版本不运行 callback，也不把任务标为完成；随后同一合法请求能完成一次。
- 删除五个针对宿主重复旧参数黑名单的测试，保留 bridge 对两种旧参数及等号形式的拒绝测试。测试数量变化不代表削弱模型参数解析入口。
- 自有生产 Python 从 **6,226 行降至 6,137 行，净减少 89 行**，含空行与注释，不含测试、文档和固定上游。

全量验收 **474 项通过，0 失败、0 跳过，耗时 216.93 秒**，包含真实 Docker 内的完整 RSI 循环；模型和评分使用确定性替身，未调用真实模型。测试期间冻结的 93 个非文档文件哈希均未变化，19 个固定上游、资产及依赖锁文件与基点一致。

在线／improvement 均保持 v8，资源、检查和恢复 schema 不变；写入布局和有效输入契约不变，已有控制清单仍阻止混用不同源码实现。未修改数据、凭据、固定资产、依赖锁或历史运行。
