## 1. 机制测试执行合同

原适配将冻结测试重命名挂载为 /mechanism/test.py，源码另挂为 /source。模型生成的 tests/mechanism_check.py 使用 __file__.parent.parent 定位项目根，因此错误地查找 /minisweagent。该错误属于宿主执行合同与模型测试约定不一致，不能用来证明新增编辑器失效。

新实现为父版本和候选各建立独立临时源码副本，将同一份冻结测试覆盖到其声明的相对路径。父版本即使没有 tests/，也只在临时副本创建目录，原归档不变。副本只读挂载为 /source；工作目录和 PYTHONPATH 为 /source，入口为 /source/<test_path>，并提供 RSI_SOURCE_ROOT。独立容器仍无网络、无评分资产、无凭据及工作流日志挂载。

固定启动器先核对根路径、入口、冻结测试SHA和可写配置目录，然后运行测试。宿主准备/入口异常、超时或容器异常退出不产生 parent_failed 收益结论。125为准备失败保留退出码，137为异常终止，均视为检查无效。普通断言失败仍可作为实际测试失败。测试超时、资源限制保持原合同。

真实容器测试进一步发现官方 mini 使用 MSWEA_GLOBAL_CONFIG_DIR，原 MSWEA_CONFIG_ROOT 无效；只读容器导入 mini 时曾尝试创建 /root/.config。已设置正确变量及 HOME=/tmp，未修改官方 mini 或生成候选代码。

前后核对父/候选完整文件摘要，保留冻结测试相同字节和SHA；运行结果附带 relative-source-overlay-v1 执行合同与准备有效标记。

## 2. 动作格式协议

文本协议显式升级为 mini-text-bash-v5。提供闭合格式白名单：标准 mswea_bash_command 围栏、bash 围栏、完整 mswea_bash_command/bash_command XML块（可带成对 tool_call 外层）。标准完整动作原样保留；其余完整单一动作转换为标准格式，命令内容交给官方 mini 解析器，权限仍由原工作流与宿主控制。

正文与空正文推理字段都走同一解析规则。普通文字提及格式名称不构成第二个动作。多个块、额外围栏、混合已知格式、空块、残缺/嵌套标签均拒绝，不补齐缺失语法、不选择最后一个块、不从普通文字猜测命令。

特别检查了“返回原文但包含一个标准块和第二个XML块”这一漏洞：官方 mini 可能只执行标准块并忽略XML。新实现将这种响应的派生正文替换为无动作的明确拒绝信息，使官方解析器确实失败；原始代理响应仍完整保留在事件记录，返回派生结果及转换/拒绝原因另记。

不修改模型、推理模式、输出/上下文容量或重试次数。原七步指令不变，第1–3步只读与仅第4步可改代码的约束不变。
