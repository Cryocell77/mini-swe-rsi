## 顺序

1. 固定源码下载与摘要；保留 SICA 原始 runner / ArchiveAnalyzer，通过可审计适配接入。
2. 受保护宿主：配置、时限、数据清单校验、模型计量代理、独立 SWE 评分。
3. 归档 mini 子进程：benchmark / improve，执行版本证据，隔离候选与私有评分。
4. baseline / evolve / evaluate / report CLI，恢复、固定改进者与配对探针。
5. 有意义的机制/隔离/预算测试；真实预检、基线、演化，按门槛条件继续。

## 验收

机制：至少两代行为变化并实际由演化 agent 继续提案。收益：两次 val 配对均严格胜过 H0、平均推理 tokens <=110%。探针：两个同起点配对均胜过固定 H0 改进者。全部通过才精简；否则失败报告且封存 test。

最终 test100 四版本各一次，配对 bootstrap 95% CI；精简版-H0 下界>0，精简版-参考版下界>=-0.03。不得将部分覆盖当完整成绩。

实验阶段上限小时：预检2、基线2、搜索/探针6、验证2、条件精简2、最终9、报告1；总24。工程实现不计入实验，首次真实模型/评测预检开始计时。
