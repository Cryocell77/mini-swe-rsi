# 围栏误判修复：审计与验收

2026-10-15 用户要求暂停实验，修复兼容层误判，完成审计、测试和验收。原实验 online-dev30-20261015-024946 已退出，本次保存工程暂停快照，未恢复数据集实验，没有真实模型调用。

## 原因

140、141、142号原始响应各有一个完整标准命令块，命令均为合法JSON的 committee 请求。官方 mini 解析器各得到恰好一个动作。兼容层却使用全文三反引号次数，并在命令正文的正则中禁止任何三反引号，将说明文字及JSON字符串中的格式/正则示例误当成多个或不完整动作。

这是兼容层代码缺陷。此前286项测试未覆盖“结构化参数里引用代码围栏”的真实场景，不能据该轮通过声称该场景已获验证。

## 修复

- 仅将独立围栏行作为代码块边界，不统计说明文字与JSON字符串里的反引号。
- 单一命令块内部允许格式示例、正则和XML字符串，数据字节不改写；关闭边界仍要求独立的闭合围栏行。
- 对围栏外的同行代码引用和双引号字符串做等长遮罩，仅用于识别XML封装；识别后从原始文本提取命令，避免把文档里的 `</tool_call>` 等示例当成未闭合动作，且不改变命令。
- 额外或残缺的真正围栏行、第二个XML动作、未闭合XML、空动作、未知围栏仍拒绝。没有选择“最后一个看起来正确”的动作，没有补齐缺失语法。
- 标准合法正文原样返回，原始代理响应保留；推理字段与已支持的完整替代格式遵循相同边界规则。
- 七步权限、模型、预算、评分和候选晋升规则保持原样。只修改宿主解析实现及回归测试，不改变 agent 解题策略。
